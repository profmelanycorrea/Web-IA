¿Cómo funciona?

Entrenamos un modelo de inteligencia artificial con Teachable Machine (Google), usando fotos de cada uno de nuestros productos. El modelo es una red neuronal que aprendió a reconocer patrones en esas imágenes. Cuando le mostrás algo nuevo, calcula qué tan parecido es a cada producto y elige el más probable.
